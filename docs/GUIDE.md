## 1. Project Overview

FashionAI replaces the original TensorFlow/Keras + sklearn codebase with a
fully **PyTorch-native** stack and adds two new pillars on top of the visual
search engine:

| Pillar | What it does | Key technology |
|--------|-------------|----------------|
| **Visual Search** | Finds visually similar garments | PyTorch ResNet-50 + FAISS |
| **CV Anthropometry** | Measures the user's body from a photo | MediaPipe Pose |
| **Size Fit Validator** | Predicts "Too Small / Fit / Too Large" | RF + PyTorch MLP ensemble |
| **Trend Oracle** | Forecasts upcoming fashion demand | Facebook Prophet |

## 5. Installation

```bash
# 1. Clone or copy the project
git clone <your-repo-url> FashionAI
cd FashionAI

# 2. Create a virtual environment
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate

# 3. Install all dependencies
pip install --upgrade pip
pip install -r requirements.txt

# 4. Verify PyTorch detects your hardware
python -c "import torch; print(torch.__version__, torch.cuda.is_available())"
```

> **GPU users:** replace `faiss-cpu` with `faiss-gpu` in requirements.txt  
> and install `torch` with the appropriate CUDA variant from pytorch.org.

## 6. Data Preparation

### 6a. Fashion Product Images (for Visual Search)

Place your **45,000+ product images** into `data/images/`.  
Supported formats: `.jpg`, `.jpeg`, `.png`, `.webp`

```
data/
└── images/
    ├── 00001.jpg
    ├── 00002.jpg
    └── ...
```

> The original Kaggle dataset:  
> - Large (15 GB): https://www.kaggle.com/datasets/paramaggarwal/fashion-product-images-dataset  
> - Small (572 MB): https://www.kaggle.com/datasets/paramaggarwal/fashion-product-images-small

### 6b. Generate Synthetic Size & Trend Data

```bash
python scripts/generate_data.py \
    --output data/ \
    --n_size 100000 \
    --seed 42
```

**What this creates:**

`data/size_data.csv` — 100,000 rows:
```
user_shoulder, user_chest, user_torso, user_arm,
item_shoulder, item_chest, item_torso, item_arm,
brand, label
```
Label: 0=Too Small · 1=Perfect Fit · 2=Too Large

`data/trend_data.csv` — weekly demand signals:
```
ds (date), category, value, y (demand index)
```

### 6c. Bring Your Own Size Data (Optional)

If you have real brand size data, format it as `data/size_data.csv` with the
same column names above. The label column must be 0/1/2.

## 7. Training (Step-by-Step)

### Step 1 — Build the FAISS Visual Index

**Input:** All images in `data/images/`  
**Output:** `artifacts/embeddings.pt`, `artifacts/faiss.index`, `artifacts/filenames.pkl`  
**Time:** ~15 min for 45k images on CPU; ~3 min on GPU

```bash
python scripts/train.py --stage index
```

You will see:
```
[Dataset] Found 45,000 images in data/images
Extracting embeddings: 100%|████████| 704/704 [14:32<00:00]
[FAISS] Index built. Vectors: 45000, Dim: 2048
✅  Visual index built and saved.
```

### Step 2 — Train the Size Fit Model

**Input:** `data/size_data.csv`  
**Output:** `artifacts/size_model.pt`, `artifacts/size_model_rf.pkl`  
**Time:** ~3–5 minutes for 100k rows

```bash
python scripts/train.py --stage size
```

You will see:
```
[SizeFit] Training on 100000 samples
[RF] Train accuracy: 0.947
[MLP] Epoch 10 | loss=0.1823
[MLP] Epoch 50 | loss=0.0612
✅  Size model trained.
```

### Step 3 — Fit the Trend Oracle

**Input:** `data/trend_data.csv`  
**Output:** `artifacts/trend_model.pkl`  
**Time:** ~5–10 minutes (Prophet fits one model per trend value)

```bash
python scripts/train.py --stage trend
```

### All at once

```bash
python scripts/train.py --stage all
```

### Visual Recommendation

```
POST /recommend?top_k=5
Content-Type: multipart/form-data
Body: file=<image>
```

**Input:** Fashion product image (JPEG/PNG)  
**Output:**
```json
{
  "recommendations": [
    {"path": "data/images/12345.jpg", "score": 0.953},
    {"path": "data/images/67890.jpg", "score": 0.941},
    ...
  ]
}
```
Score is cosine similarity (0–1, higher = more similar).

```bash
# Example curl
curl -X POST http://localhost:8000/recommend \
  -F "file=@my_shirt.jpg" \
  -F "top_k=5"
```

### CV Body Scan

```
POST /fit/scan
Content-Type: multipart/form-data
Body: file=<user_photo>, reference_px=<float> (optional)
```

**Input:**  
- User's front-facing upper-body photo  
- `reference_px`: pixel width of A4 paper held in the photo (for accurate scale)

**Output:**
```json
{
  "shoulder_width_cm": 44.3,
  "chest_width_cm":    93.7,
  "torso_length_cm":   43.9,
  "arm_length_cm":     57.2,
  "confidence":        0.921
}
```

Confidence is MediaPipe's average landmark visibility for key joints.

```bash
curl -X POST http://localhost:8000/fit/scan \
  -F "file=@user_photo.jpg" \
  -F "reference_px=312"
```

## 10. Dashboard Guide

### Tab 1 — Visual Search
1. Upload any product image (JPG/PNG)
2. Adjust the "Number of results" slider (1–10)
3. Similar items from your catalogue appear with cosine similarity scores

### Tab 2 — Body Scan & Fit
1. **Scan** — Upload a front-facing photo. Optionally measure the pixel width of an A4 paper you're holding for accurate cm conversion.
2. Your 4 measurements appear (shoulder, chest, torso, arm).
3. **Item Spec** — Enter the garment's technical measurements (from the brand's size guide).
4. **Predict** — See "Too Small / Perfect Fit / Too Large" with a clearance bar chart per dimension.

### Tab 3 — Trend Heatmap
1. Select a category (color, silhouette, garment type)
2. Click "Load Forecast"
3. A demand heatmap shows week-by-week forecasted demand
4. A ranked table lists trends by average forecasted demand

## 11. Input / Output Contracts

| Module | Input | Output |
|--------|-------|--------|
| FeatureExtractor.build_index | `data/images/` folder | `artifacts/*.pt/.index/.pkl` |
| FeatureExtractor.recommend | PIL Image or image path | `[{path, score}, ...]` |
| CVAnthropometry.measure | BGR numpy array or image path | `AnthropometryResult` dataclass |
| SizeFitModel.train | `size_data.csv` | saved `.pt` + `.pkl` files |
| SizeFitModel.predict | `FitRequest(user_body_cm, item_size_cm, brand)` | `FitVerdict(label, confidence, clearance, message)` |
| TrendOracle.fit | `trend_data.csv` | saved `trend_model.pkl` |
| TrendOracle.top_trends | horizon_days (int) | `[{category, value, growth_pct, peak_date}]` |

## 12. Configuration Reference

All settings live in `configs/config.yaml`. Key fields:

```yaml
feature_extractor:
  backbone: resnet50        # resnet50 | efficientnet_b3 | vit_b_16
  batch_size: 64            # increase for GPU
  device: auto              # auto | cuda | cpu | mps

size_model:
  rf_n_estimators: 200
  mlp_hidden: [256, 128, 64]
  epochs: 50

cv_anthropometry:
  reference_object_cm: 21.0   # real-world width of your reference object

trend_forecasting:
  forecast_horizon_days: 90
  seasonality_mode: multiplicative
```

## 13. Troubleshooting

| Problem | Fix |
|---------|-----|
| `No images found in data/images` | Place your images there — check file extensions |
| `MediaPipe could not detect a pose` | Use a clear front-facing photo, good lighting |
| `size_model.pt not found` | Run `python scripts/train.py --stage size` |
| `FAISS index not ready` | Run `python scripts/train.py --stage index` |
| `ModuleNotFoundError: prophet` | `pip install prophet` (requires pystan, may take 5 min) |
| Slow indexing on CPU | Set `batch_size: 128` in config, or use a GPU |
| Port 8000 already in use | `uvicorn src.api.main:app --port 8001` |
